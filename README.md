# 그랜드슬램 2026

Python과 Pygame으로 만든 3이닝 야구 게임입니다. AI 대전과 한 컴퓨터에서 두 사람이 번갈아 조작하는 오프라인 PvP를 지원합니다.

## 실행

Python 3.13과 Pygame 2.6.1 환경에서 검증했습니다. 게임 창을 표시할 수 있는 데스크톱 환경이 필요합니다.

프로젝트 폴더에서 다음 명령을 실행하세요.

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 Grandslam2026.py
```

이미 가상환경을 설치했다면 매번 다음 명령으로 실행할 수 있습니다.

```bash
cd /home/student11/save-space01
source .venv/bin/activate
python Grandslam2026.py
```

Windows에서는 `python3` 대신 `py`를 사용하고, 가상환경은 PowerShell에서 `.venv\Scripts\Activate.ps1`로 활성화합니다.

## 조작

시작 화면에서 `AI 대전` 또는 `2인 PvP`를 선택합니다.

| 입력 | 동작 |
| --- | --- |
| Enter | 게임 시작 / 다음 투구 시작 |
| 마우스 이동 | 타격 시 배트 조준 |
| 마우스 왼쪽 클릭 | 투구 시 목표 위치 지정 (경기장 안) |
| 1 / 2 / 3 | 투구 대기 중 직구 / 커브 / 슬라이더 선택 |
| Space | 스윙 (투구 대기 중에는 투구 시작) |
| Esc | 종료 |

## 투구 속도 설정

화면 오른쪽 위의 `설정` 버튼이나 `F1`로 설정창을 엽니다. 슬라이더를 드래그하면 투구 속도를 기본 속도의 `0.5배`부터 `2.0배`까지 `0.1배` 단위로 조절할 수 있습니다. 설정한 속도는 AI 대전과 PvP의 다음 투구부터 적용됩니다. 설정창이 열려 있는 동안 경기는 일시정지됩니다. `Esc`, `F1` 또는 `X`로 닫습니다.

### 2인 PvP

1회초에는 P1이 투수, P2가 타자입니다. 1회말에는 P2가 투수, P1이 타자이며, 매 이닝 같은 순서로 교대합니다. 3회말이 끝나면 P1과 P2의 점수로 승패를 정합니다.

1. 투수가 `1`/`2`/`3`으로 구종을 고르고 경기장을 클릭해 투구 위치를 지정합니다.
2. 투수가 `준비 완료` 버튼이나 `Enter`/`Space`를 누르면 목표가 고정되고 화면이 가려집니다.
3. 타자가 화면을 넘겨받아 `시작` 버튼이나 `Enter`/`Space`를 누르면 투구가 시작됩니다.
4. 타자는 마우스로 배트를 조준하고 공이 가까워졌을 때 `Space`로 스윙합니다. 다음 투구부터 같은 순서를 반복합니다.

플레이어는 홈팀입니다. 1회초부터 매 이닝 초에는 플레이어가 투구하고 AI가 타격하며, 말에는 플레이어가 타격합니다. 3아웃이면 공수를 교대하며 주자와 카운트를 초기화합니다. 3회말까지 모두 진행한 뒤 승패를 표시하고, 동점이면 무승부로 끝납니다.

투구할 때는 구종을 선택하고 존 안이나 밖의 목표를 클릭한 다음 Enter 또는 Space로 던지세요. 목표와 구종은 투구 준비를 시작할 때 고정됩니다. 변화구도 선택한 목표에 도착합니다.

타격할 때는 공이 투구 목표에 도착할 때 스윙 중이도록 맞추거나, 도착한 뒤 약 0.22초 안에 스윙하세요. 공이 날아오는 중 조준 위치를 지나가도 타격되지 않습니다. 한 투구에는 한 번만 스윙할 수 있습니다.

## 구현된 기능

- 1280×900 낮은 타석 시점 경기장: 화면 중간의 수평선과 낮게 보이는 내야
- 타자 어깨부터 무릎까지의 스트라이크 존, 다리 들기·보폭·머리 위 릴리스·팔로스루 투구폼
- 타자의 무릎 굽힌 준비 자세와 스윙·팔로스루 동작, 타격 판정 크기와 같은 조준 가이드
- 파울라인 위의 1·3루 베이스와 베이스별 주자 표시
- 거리에 따라 커지는 투구
- 내야수 4명·외야수 3명: 주자 유무와 관계없이 기본 수비 위치 유지
- 직구·슬라이더·초반에 살짝 떠올랐다가 후반에 급히 떨어지는 커브, 투구 원근 효과와 잔상
- 타자 몸통 회전, 배트 궤적 잔상, 임팩트와 팔로스루 애니메이션
- 내야를 직선으로 통과하는 땅볼 1루타, 외야 앞에 떨어지는 뜬공 1루타
- 외야 사이로 향하는 포물선 2루타, 좌우 구석으로 향하는 포물선 3루타
- 홈런·뜬공·땅볼 타구 애니메이션
- 볼넷, 삼진, 병살, 진루·팀별 득점, 초·말 교대 및 3회말 종료 처리
- 플레이어 투구 조작, AI 타자의 스윙·컨택·안타 판단, 양 팀 파울 및 파울 타구 애니메이션

공이 투구 목표에 도착했을 때 조준 위치와 배트가 맞으면 즉시 타구가 시작되고, 타구 애니메이션 종료 후 결과를 반영합니다. 헛스윙한 공은 원래 도착점까지 진행합니다. 타구 결과는 배트 접촉 부위에 따른 확률로 결정하며, 수비수 추적이나 포구 동작은 구현하지 않았습니다.

## AI 타격 확률

각 확률은 순서대로 적용합니다. 컨택은 스윙했을 때, 안타는 컨택했을 때의 확률입니다. 커브와 슬라이더는 같은 변화구 확률을 사용합니다.

| 위치·구종 | 스윙 | 컨택 | 안타 |
| --- | ---: | ---: | ---: |
| 존 안 직구 | 70% | 50% | 50% |
| 존 안 변화구 | 45% | 70% | 60% |
| 존 밖 아래쪽 직구 | 10% | 0% | 발생하지 않음 |
| 존 밖 나머지 직구 | 40% | 30% | 40% |
| 존 밖 위쪽 변화구 | 10% | 0% | 발생하지 않음 |
| 존 밖 나머지 변화구 | 70% | 10% | 70% |

위·아래 모서리에서도 높낮이 조건을 우선합니다. 공 중심이 존 오른쪽 또는 아래 경계에 있으면 존 밖입니다.

안타가 확정된 뒤 종류를 아래 비율로 추첨합니다.

| 위치·구종 | 1루타 | 2루타 | 3루타 | 홈런 |
| --- | ---: | ---: | ---: | ---: |
| 존 안 직구 | 65% | 22% | 3% | 10% |
| 존 안 변화구 | 70% | 20% | 3% | 7% |
| 존 밖 직구 | 78% | 17% | 2% | 3% |
| 존 밖 변화구 | 82% | 14% | 2% | 2% |

AI가 컨택했지만 안타가 아니면 30%는 파울, 나머지는 뜬공·땅볼을 반반으로 배분합니다. 플레이어는 배트 중심 컨택의 15%, 손잡이 컨택의 35%가 파울이며, 나머지는 기존 타격 확률을 사용합니다. 양 팀 모두 파울은 스트라이크를 최대 2개까지만 늘리며 볼·아웃·주자는 유지합니다.

GitHub 연결을 마친 뒤 코드를 수정하면 다음 순서로 기록합니다.


## 한글 폰트
